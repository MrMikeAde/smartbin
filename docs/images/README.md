# SmartBin Application Screenshots Guidelines

This directory is dedicated to storing application screenshots and UI captures for the GitHub repository documentation.

---

## Recommended Screenshot Asset Inventory

When capturing screenshots on a Windows 10/11 environment running the WinUI 3 application, save PNG files into this directory using the following naming conventions:

| Filename | View / Screen Description |
| :--- | :--- |
| `01-dashboard.png` | Main WinUI 3 dashboard showing drive storage gauge and system state |
| `02-recycle-bin.png` | "Windows Recycle Bin" tab showing discovered candidates and candidate scores |
| `03-controlled-experiment.png` | "Controlled Experiment" tab showing the 11-stage pipeline execution |
| `04-settings.png` | "Settings" tab showing policy controls, safety floor, and battery toggle |
| `05-activity-history.png` | "Activity History" tab showing persisted log history entries |

---

## Capture Requirements

1. **Resolution:** High-DPI capture (1920x1080 or 4K scaled cleanly).
2. **Theme:** Windows 11 Dark Mode or Light Mode (consistent across all captures).
3. **Data:** Capture UI using synthetic test data generated by `TestFileGenerator`.
4. **Privacy:** Ensure no personal user file paths, usernames, or confidential documents are visible in the captured frames.
