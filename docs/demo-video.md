# SmartBin — Demonstration Video Recording Script

This script outlines a concise 60 to 120 second video demonstration demonstrating SmartBin's problem, core concept, controlled optimization pipeline, and byte-for-byte restoration verification.

---

## Video Overview

* **Target Duration:** 90 seconds
* **Target Audience:** Technical evaluators, software engineers, open-source contributors
* **Key Theme:** "Same file. Verified restorable. Reduced footprint."

---

## Script & Timeline

| Time | Visual / Screen Focus | On-Screen Text / Voiceover |
| :--- | :--- | :--- |
| **0:00 - 0:10** | Title screen & Windows Recycle Bin filled with large log/text files | *"When deleted files sit in the Windows Recycle Bin, they consume full disk space, driving storage pressure."* |
| **0:10 - 0:25** | Open SmartBin App Dashboard showing drive gauge & discovered candidates | *"SmartBin explores whether recoverable deleted files can stop occupying their full footprint without permanent loss."* |
| **0:25 - 0:40** | Navigate to Controlled Experiment tab, select 10 MB synthetic text candidate | *"Select a single candidate item. SmartBin runs candidate revalidation and prepares a trial compression."* |
| **0:40 - 0:55** | Show live terminal log advancing through 11-stage safety pipeline | *"Content is extracted, hashed with SHA-256, deflated, and decompressed in a dry-run to verify integrity."* |
| **0:55 - 0:70** | Click Commit. Show storage gauge updated (10 MB -> 15 KB, 99.8% space reclaimed) | *"Upon explicit user commit, the compressed representation is stored locally, reclaiming physical disk space."* |
| **0:70 - 0:85** | Click Restore. File restored to `C:\Temp\Restored`. Open PowerShell terminal showing SHA-256 comparison | *"On restore, SmartBin decompresses the file and verifies SHA-256 stream hashes match down to the bit."* |
| **0:85 - 0:90** | End card with GitHub link & tagline | *"Same file. Verified. SmartBin — Adaptive Storage Exploration."* |
