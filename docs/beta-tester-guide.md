# SmartBin — External Beta Tester Guide

Welcome to the SmartBin Beta Testing Program (`v1.0-rc1`)! This guide provides all necessary instructions for testing SmartBin safely and reporting feedback.

---

## Safety Directives for Beta Testers

> **CRITICAL SAFETY DIRECTIVE:** During beta testing, MUST strictly perform test workflows using synthetic test files generated by SmartBin's built-in generator or disposable non-essential test documents. Never run initial tests on your primary personal documents.

---

## System Requirements

* **OS:** Windows 10 (1809+) or Windows 11 (x64 or ARM64)
* **Runtime:** .NET 10.0 Desktop Runtime
* **Permissions:** Standard user mode (No Administrator privileges required)

---

## Recommended Testing Sequence

### 1. Launch & Onboarding
1. Launch `SmartBin.App.exe`.
2. Review the Welcome Guide onboarding tab.
3. Verify that **Automatic Protection is OFF by default** in the Settings tab.

### 2. Controlled Optimization Test
1. Click **"Generate Test File"** in the UI (or run `TestFileGenerator`) to create a 10 MB synthetic text file.
2. Delete the generated test file to the Windows Recycle Bin.
3. Open SmartBin and navigate to the **"Windows Recycle Bin"** tab.
4. Verify the file appears in the candidates list.
5. Go to **"Controlled Experiment"** tab, select the test candidate, and click **"Prepare Optimization"**.
6. Observe the terminal logs tracking candidate acquisition, baseline SHA-256 calculation, trial compression, and dry-run decompression verification.
7. Click **"Commit Optimization"** and confirm physical disk space recovery.

### 3. Verification & Restoration Test
1. Navigate to **"SmartBin Storage"**.
2. Select the compressed test file and click **"Restore"**.
3. Specify a target restore folder (e.g., `C:\Temp\Restored`).
4. Verify that the file is restored cleanly and its SHA-256 hash matches the baseline.

### 4. Edge Case & Failure Testing
* **Destination Conflict:** Attempt to restore a file to a destination where a file with the same name already exists. Verify that SmartBin blocks the restore and preserves the existing file.
* **Low Space Floor:** Set the safety floor in Settings higher than your current drive free space. Verify that automatic protection stops cleanly.

## What & How to Report

If you encounter any issues, submit a report using the [Beta Bug Report Template](https://github.com/MrMikeAde/smartbin/issues/new?template=beta_bug_report.md).

### Required Details:
* **SmartBin Version:** `v1.0-rc1`
* **Windows Version & Architecture:** (e.g. Windows 11 23H2 x64 / ARM64)
* **File Type & Size:** (e.g. 10 MB `.txt` synthetic file)
* **Observed vs Expected Behavior:** Clear step-by-step description
* **Error Log / Diagnostic Message:** (from the UI terminal log)
